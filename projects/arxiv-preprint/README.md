# arXiv-ready LaTeX sample (two columns)

`main.tex` is a typesetting sample that follows the usual arXiv requirements, in a **two-column** layout (10 pt, A4, 3 pages).
It is **not** a research submission: it demonstrates the formatting, the packaging and the reproducibility workflow.

## What is in this folder

| File | Role |
|---|---|
| `main.tex` | The article, two columns (`article` class, `twocolumn` option, pdfLaTeX). First line is `\pdfoutput=1`, as arXiv recommends. |
| `main.bbl` | Compiled bibliography. arXiv does **not** run BibTeX, so the `.bbl` must be uploaded. |
| `references.bib` | BibTeX database (optional on arXiv, useful for readers). |
| `quadrature.py` | Script that recomputes every number, table and curve of the paper. |
| `data/*.csv` | Error curves read by `pgfplots` (generated by `quadrature.py`). |
| `table-results.tex`, `table-evals.tex` | Complete tables generated by `quadrature.py`. |
| `arxiv-submission.zip` | The files above, ready to upload. |
| `main.pdf` | The compiled two-column result. |
| `main-1col.tex`, `main-1col.pdf` | The same article in a single column (5 pages), kept for comparison. |

## Layout choices for two columns

- Title, authors and abstract span both columns through `\twocolumn[...]`.
- Long equations (Simpson's rule, the Gauss--Legendre error) are split over several lines.
- The three convergence plots and the table of test integrals use `figure*` / `table*` so they span the full page width.
- The other tables use short labels ($f_1$, $f_2$, $f_3$) to fit one column.
- The appendix listing uses a smaller font with short lines.

## Checklist applied

- Standard packages only, no `fontspec`, no `minted`, no shell-escape.
- Single main file at the top level, flat structure plus one `data/` folder.
- Bibliography compiled locally and shipped as `main.bbl`.
- All figures are drawn with `pgfplots`/TikZ from CSV data, so there are no image files to convert.
- The archive was compiled from scratch in an empty folder with `pdflatex main.tex` (twice), without BibTeX, and produced no warning about undefined references or citations.

## Rebuild from the sources

```bash
python quadrature.py          # regenerate data/*.csv and the table files
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

## Before a real submission

1. Compile once more, then copy the new `main.bbl`.
2. Remove temporary files (`*.aux`, `*.log`, `*.out`, `*.blg`) and the PDF from the archive.
3. Check the metadata (title, authors, abstract, MSC codes) on the arXiv submission form.
4. Choose the license and the subject class.
